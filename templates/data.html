Importer

Accepte ton tableau Excel (.xlsx) ou un CSV : la ligne d'en-tête est repérée automatiquement (colonne « Entreprise »), les autres colonnes sont associées par leur nom, les liens hypertexte sont récupérés. Accepte aussi un export .json ou une sauvegarde .zip de cette application.

Mode d'import

Exporter

  • Export JSON toutes les données : candidatures, sections, historique, liste des fichiers
  • Export CSV (Excel) une ligne par candidature, s'ouvre directement dans Excel
  • Sauvegarde complète (.zip) JSON + fichiers joints, se ré-importe ici
