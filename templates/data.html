Importer

Accepte ton tableau Excel (.xlsx) ou un CSV : la ligne d'en-tête est repérée automatiquement (colonne « Entreprise »), les autres colonnes sont associées par leur nom, les liens hypertexte sont récupérés. Accepte aussi un export .json ou une sauvegarde .zip de cette application.

Mode d'import

Exporter

  • Export JSON toutes les données : candidatures, sections, historique, liste des fichiers
  • Export CSV (Excel) une ligne par candidature, s'ouvre directement dans Excel
  • Sauvegarde complète (.zip) JSON + fichiers joints, se ré-importe ici

API en lecture : /api/applications et /api/applications/{id}.

Marque-page « Capturer l'offre »

Glisse ce bouton dans ta barre de favoris :

＋ Capturer l'offre

Sur la page d'une annonce (Workday, Hellowork, WTTJ, LinkedIn…), clique dessus : un nouvel onglet s'ouvre avec le formulaire pré-rempli (lien, poste, entreprise, lieu) et le texte de l'offre archivé. Si tu sélectionnes un passage avant de cliquer, seul ce passage est gardé.

Le marque-page pointe vers {{.Base}}. Si tu changes d'adresse (domaine, Tailscale…), recrée-le depuis cette page. Quelques sites bloquent l'envoi de formulaires vers un autre domaine : dans ce cas, utilise « Remplir depuis le lien » ou copie-colle le texte.

Rappels

Une relance est proposée quand sa date est atteinte, ou {{.RelanceDays}} jours après l'envoi s'il n'y en a pas (RELANCE_DAYS).

{{if .Ntfy}}

Notification ntfy chaque jour à {{.NotifyHour}} h vers {{.Ntfy}} s'il y a des relances ou des entretiens.

{{else}}

Notifications désactivées. Renseigne NTFY_URL dans le docker-compose pour recevoir chaque matin les relances et entretiens du jour sur ton téléphone.

{{end}}
